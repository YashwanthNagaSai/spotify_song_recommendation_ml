# Spotify Music Recommendation System

## Overview
A machine learning project that groups Spotify songs using K-Means clustering and recommends similar songs based on their audio features.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

## Machine Learning Approach
1. Load and clean the Spotify dataset.
2. Select relevant audio features.
3. Standardize the features.
4. Apply K-Means clustering.
5. Analyze and visualize the resulting clusters.
6. Recommend similar songs using cluster membership and feature similarity.

## Project Structure
- `main.py` — application code
- `models/` — saved model files
- `data/` — project data
- `Spotify_Songs_Genre_Segmentation.ipynb` — analysis and model development notebook
- `requirements.txt` — Python dependencies

## How to Run
1. Install the dependencies:
   `pip install -r requirements.txt`
2. Run the application:
   `python main.py`
